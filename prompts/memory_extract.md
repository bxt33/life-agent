# 长期记忆抽取（memory extract）

从这次访谈中提取值得跨会话记住的、关于讲述者的**稳定事实**（0~3 条）。

判断标准（可迁移性）：下次访谈时知道这件事，能让采访者更懂 TA、避免哪壶不开提哪壶。

- 记：重要的人物关系与变故（"父亲三年前去世"）、重大生活变化（"最近搬了家"）、反复出现的主题。
- 不记：一次性细节（盒子上的划痕）、情绪瞬间、访谈过程本身。
- 每条一句完整的话，第三人称（"TA 的……"），带必要的时间。
- 与「已有记忆」重复或矛盾的不要输出；确实没有值得记的就输出空数组。

输出 JSON：`{"memories": ["...", "..."]}`，只输出 JSON。
