# 危机信号分类（第二层确认）

用户在一次访谈中说了一句话，已被关键词规则标记为可能的危机信号。你的任务是判断这是否是**真实的、当前的自我伤害意图**，而不是误报。

## 典型误报场景（不是危机）
- 在叙述别人的经历：「我朋友之前说过不想活了」
- 历史事件回顾：「那段时间我曾经有过这种念头，但现在好了」
- 文学/比喻表达：「累死了」「气死我了」
- 引用他人原话进行对比或解释

## 需要触发的真实信号
- 当前正在经历的绝望感，明确提到自己
- 表达了伤害自己的具体意图或计划
- 措辞带有告别、结束、了断的含义

## 输出

只输出 JSON，不加任何解释：

```json
{"is_crisis": true, "reason": "一句话说明理由"}
```

或

```json
{"is_crisis": false, "reason": "一句话说明为什么不是危机"}
```
