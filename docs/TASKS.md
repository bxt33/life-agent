## 使用规则

1. **每次开发会话开始**：读本文档「进行中」+ 当前里程碑，接着干。
2. **每次开发会话结束**：更新勾选状态，把完成项移入「已完成」表；有新发现的任务就近插入对应里程碑。
3. **任何方向/方案变更**：先记入「决策与变更日志」，再同步修改 PRD/TECH 对应章节。
4. 文档更新与代码同一个 commit 提交，保持一致。
5. 里程碑内按顺序做；跨里程碑并行要有理由（记入日志）。
